# Django Shop - Слугинов А.П.

Онлайн-магазин на Django для изучения GitFlow и командной разработки.

## Технологии

- Python 3.11+
- Django 5.0
- PostgreSQL (опционально)
- Poetry для управления зависимостями

## Структура веток

- `main` — стабильная production версия
- `develop` — основная ветка разработки
- `test` — ветка для тестирования
- `feature/*` — ветки для новых функций

## Установка

### 1. Клонировать репозиторий

bash
git clone https://github.com/Bibindum1/django-shop-Sluginov
cd django-shop-Sluginov
git checkout develop
